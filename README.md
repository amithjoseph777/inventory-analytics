#  Inventory Management Optimization for SMEs  
*A data-driven approach to improve inventory control using Python and Power BI*

---

##  Overview  
This project focuses on analyzing and optimizing inventory management for small and medium-sized enterprises (SMEs). It uses historical sales and stock data to identify patterns, predict future demand, and recommend a cost-effective replenishment strategy.

---

##  Tools & Technologies  
- **Python**: Data cleaning, forecasting (e.g., ARIMA, Prophet)  
- **Pandas / NumPy / Matplotlib / Seaborn**: Data analysis & visualization  
- **Power BI**: Interactive dashboards for business insights  
- **Excel**: Supplementary data formatting and validation

---

##  Key Objectives  
- Analyze stock movement and order trends  
- Forecast demand using time series models  
- Minimize both stockouts and excess inventory  
- Build a user-friendly Power BI dashboard to support decision-making

---

##  Outputs  
- Demand forecast model (`.ipynb`)  
- Power BI dashboard (`.pbix` or `.png`)  
- Sample datasets (anonymized)  
- Final summary report (`.pdf`)
